## Stacking y = x^2

The stack at each column counts **f(x)**. For x² the counts are 0, 1, 4, 9, 16.

- First differences: Δy
- Second differences: Δ²y/Δx²

| x | y | Δy |
| - | - | -- |
| 0 | 0 | 1 |
| 1 | 1 | 3 |
