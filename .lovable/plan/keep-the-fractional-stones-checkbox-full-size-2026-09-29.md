# Keep the Fractional Stones checkbox full size

When Dual Increments is applied, the Fractional Stones row adds the note “(needed for dual increments).” The checkbox sits in a flexible row without a no-shrink rule, so the extra text can squeeze it.

## Change
- Keep the Fractional Stones checkbox at its intended size when the note appears, while allowing the explanatory text to wrap within the panel.
- Apply the same size protection to the neighboring checkbox so the two primary controls remain consistent.
- Leave the automatic Fractional Stones setting and disabled state unchanged.

## Check
- Compare the checkbox sizes before and after checking Dual Increments and clicking Fill Board, including at a narrower viewport.
